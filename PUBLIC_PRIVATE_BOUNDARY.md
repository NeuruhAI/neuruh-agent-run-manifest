# Public / Private Boundary

## Public in this repository

- neutral run identity and timing;
- content hashes for inputs, outputs, evidence, decisions and executions;
- public component/version references;
- policy identity + content-derived version reference;
- inference backend/model labels and health state;
- Agent Receipt references;
- deterministic manifest digest and fail-closed validator;
- synthetic fixtures only.

## Explicitly excluded

- production Neuruh routing or orchestration;
- production authority topology;
- private policies or thresholds;
- private prompts or memory;
- proprietary scoring, recipes or domain intelligence;
- production connector graph;
- credentials, customer data or production endpoints.

A manifest is evidence about a run. It is not authorization.
